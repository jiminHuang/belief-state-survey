\section{Problem Formulation}
\label{sec:formulation}

Partially observed decision-making defines the belief as the distribution over hidden variables that is sufficient for acting: with hidden state $z_t$, observation $o_t$, and history $\hist_t$, the belief is $\belief_t = p(z_t \mid \hist_t)$ \citep{astrom1965optimal,kaelbling1998planning}, and a Bayes filter carries it forward as
\begin{equation}
\belief_{t+1}(z') \propto p(o_{t+1} \mid z') \textstyle\sum_{z} p(z' \mid z, a_t)\, \belief_t(z)
\label{eq:filter}
\end{equation}
\citep{thrun2005probabilistic}, whose three factors are the three parts of Section~\ref{sec:intro}: the \emph{state term} $\belief_t$ says what is believed and how firmly, the \emph{transition term} $p(z' \mid z, a_t)$ carries it across the action, and the \emph{likelihood term} $p(o_{t+1} \mid z')$ scores it against the observation that returns. Agentic reinforcement learning casts the language-model agent as such a POMDP, with the context as history and any explicit state in a working memory the model writes \citep{zhang2025landscape,sumers2023cognitive}; in ReAct the reasoning segment before each action is where it lives \citep{yao2023react}. We write $\belief_t$ for whatever explicit state the span carries before the action $a_t$.

We call such an object a \emph{belief state} only if it meets three conditions: (i) it is a claim about the environment carried between decisions; (ii) it carries, or admits, uncertainty; (iii) a returned observation can change it. Conditions (i) and (ii) are properties of the state term and fix the operation \op{Construct}; condition (iii) requires a likelihood term and fixes \op{Test}, committing to a prediction an observation can falsify; \op{Revise} is the transition term, which belief-revision theory constrains to change the claim without discarding the rest \citep{alchourron1985logic,friston2010free}. We therefore place every system by which of the three terms it has and where each comes from: written by the model, fixed by the designer, learned from data, or absent. A \emph{memory} stores traces, a state term without uncertainty and without a likelihood, so it fails (i) and (ii) \citep{luo2026storage}; a \emph{world model} is a learned transition and likelihood whose state the agent cannot read, so it meets (iii) but seldom (i) \citep{li2026bridging}; a reasonable action under a stale belief is invisible to both.
