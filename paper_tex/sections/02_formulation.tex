\section{Problem Formulation}
\label{sec:formulation}

A belief $\belief_t$ is a hypothesis about the environment that the agent carries between decisions. It yields a prediction, evidence $o_{t+1}$ returns, a \emph{test relation} supports or falsifies the hypothesis, and a revision produces $\belief_{t+1}$ for the next action (Fig.~\ref{fig:loop}); the test may be a symbolic verifier, a consistency check, or a comparison with an external record. Partially observed decision-making gives this cycle its most principled realisation \citep{astrom1965optimal,kaelbling1998planning}: with hidden state $z_t$ and history $\hist_t$, the belief is $\belief_t = p(z_t \mid \hist_t)$, and a Bayes filter carries it forward as
\begin{equation}
\belief_{t+1}(z') \propto p(o_{t+1} \mid z') \textstyle\sum_{z} p(z' \mid z, a_t)\, \belief_t(z)
\label{eq:filter}
\end{equation}
\citep{thrun2005probabilistic}. We use its three factors to organise the review: the \emph{state term} $\belief_t$ says what is believed and how firmly, the \emph{transition term} $p(z' \mid z, a_t)$ carries it across the action, and the \emph{likelihood term} $p(o_{t+1} \mid z')$ is the test in probabilistic form; a verifier or consistency check is a non-probabilistic test of the same kind and is coded under the same term. Agentic reinforcement learning casts the language-model agent as such a POMDP, with the context as history and any explicit state in a working memory the model writes \citep{zhang2025landscape,sumers2023cognitive,yao2023react}; we write $\belief_t$ for whatever explicit state the span carries before the action $a_t$.

We call such an object a \emph{belief state} only if it meets three conditions: (i) it is a claim about the environment carried between decisions; (ii) it carries, or admits, uncertainty; (iii) a returned observation can change it. Conditions (i) and (ii) are properties of the state term and fix the operation \op{Construct}; condition (iii) requires a test and fixes \op{Test}, committing to a prediction an observation can falsify, which makes the state a hypothesis rather than a record; \op{Revise} is the transition term, which belief-revision theory constrains to change the claim without discarding the rest \citep{alchourron1985logic,friston2010free}. We therefore place every system by which of the three terms it has and where each comes from: written by the model, fixed by the designer, learned from data, or absent. A trace \emph{memory} fails (i) and (ii); a store that attaches a probability and an update rule to each item meets them but scores nothing against what returns, so it fails (iii) \citep{luo2026storage}; a \emph{world model} is itself a revisable hypothesis, a learned transition and likelihood whose state the agent cannot read, so it meets (iii) but seldom (i) \citep{li2026bridging}.
