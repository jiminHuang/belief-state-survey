\label{sec:representation}

\input{tab_reprprops}

The belief state is placed by two attributes rather than by method family: its \emph{locus} (in the context, in a store outside the model, in an external estimator, or in learned dynamics), which also says who writes it, and its \emph{form} (a trace, a claim, or a distribution). The classes in Table~\ref{tab:reprprops} are locus--form pairs, so a system can occupy more than one, and the last column records which of conditions (i)--(iii) each class meets; Fig.~\ref{fig:repr} and Table~\ref{tab:master} in the appendix place every system.

\subsection{Context and Memory}
\label{sec:repr:memory}

The most common design has no representation at all: the reasoning trace is the state \citep{wei2022chain,yao2023react}, the belief implicit and its uncertainty unstated.

Memory-augmented agents moved the state into a store retrieved into context \citep{packer2023memgpt,park2023generative,zhong2024memorybank,xu2025amem,luo2026storage,jiang2026jevmem}. Two limits matter for belief: the stored unit is a trace rather than a claim with a probability, and an update is an operation on the store rather than on a hypothesis, so answer accuracy hides failures in the update and forget operations themselves \citep{hao2026memops}. Structured stores narrow the first limit with schemas, graphs, bitemporal transitions, or AGM revision semantics \citep{luo2026graph,xu2026governed,park2026graph}; probabilistic stores narrow the second by attaching a number to each claim \citep{liao2026belief,song2026d,yang2026belief,zhang2026toward}.

\subsection{External Bayesian Filters}
\label{sec:repr:filter}

A different line takes the belief out of the model. The model maps evidence to a likelihood over a fixed set of latent regimes, hypotheses, or user states, and an explicit filter maintains the posterior, whose entropy and drift can then be reported as model risk \citep{chattopadhayay2026belief,dixon2026belief,wu2026bayesevolve,soru2026semantic,akbar2026bayesian,azran2026bridging,ansell2026clueing}. These beliefs are validated against a closed-form oracle and auditable by construction; the price is a hypothesis space fixed in advance.

\subsection{Model-Written Beliefs}
\label{sec:repr:written}

The third line keeps the belief in context but gives it structure the model writes and reads. Dialogue state tracking wrote a slot-value belief \citep{lee2021dialogue}, verbalised confidence attached a probability to an answer \citep{lin2022teaching,kadavath2022language}, agents wrote beliefs about tasks, opponents, and markets \citep{kim2024qube,christakopoulou2024agents,cross2024hypothetical,yu2024fincon}, MEM1 learned to overwrite a fixed written state each turn \citep{zhou2025mem1}, ReflAct reflected on a goal state before each action \citep{kim2025reflact}, and CoEx kept a neurosymbolic belief that co-evolves with exploration \citep{kim2025coex}. The newest systems add uncertainty and verification to the written object, from certainty tags and Bayesian-teacher posteriors to symbolic verification and populations of causal models \citep{singh2026agent,cui2026distilling,xu2026should,zhao2026evoscm}.

Condition (iii) separates them: a written belief is testable only if it names a future observation with a horizon, so that the returned observation yields a signed error. Most written beliefs are calibrated but not testable, stating confidence without naming what would falsify it; Hypothetical Minds, CBM, EvoSCM, and ReBel \citep{tang2026rewarding} do.

\subsection{Learned World Models}
\label{sec:repr:wm}

The fourth line learns the dynamics and exposes the resulting belief to the policy: recurrent latent states \citep{ha2018world,hafner2019learning,hafner2023mastering}, the language model as its own world model for tree search \citep{hao2023reasoning,zhao2023large,zhou2023language}, LLM-proposed POMDPs refined to a belief-based likelihood \citep{six2026learning}, and a world-model belief the policy can query \citep{kumar2026towards,li2026bridging,zuo2026qwenagentworld}. World-model beliefs are testable by construction but, unless written back, cannot be reasoned about in language. Hybrids use the learned model as a check on a written belief: a parametric consistency gate cuts the hallucinated-state rate from 0.176 to 0.035 \citep{song2026agent}. 

\insight{1}{\textbf{Structure is not testability.} Memory design has made the belief steadily more structured without making it testable, and the representations that are testable, filters and world models, cannot be reasoned about in language. The belief the field needs is written and testable at once; the first system to test one against the environment does so with a binary belief.}
