\section{Revision and Its Failures}
\label{sec:revision}

Bayesian filtering and active inference agree on how a belief should change: it predicts, evidence arrives, and the mismatch drives the update \citep{friston2010free,friston2017active}, routed by factor graphs to the factors that produced the prediction \citep{kschischang2001factor,loeliger2004introduction}. In Equation~\ref{eq:filter} the transition carries the belief forward and the likelihood decides how far the observation moves it; the language-model literature imported the vocabulary but rarely the routing: feedback is appended to the context or folded into self-critique loops \citep{huang2022inner,madaan2023self,kim2023language}.

\subsection{Four Failure Modes}
\label{sec:rev:modes}

Contextual Belief Management names three ways a belief can fail on new input, a \emph{failed stay} in which the belief moves without evidence (an update no test weighs), a \emph{failed update} in which it survives evidence against it (carried forward without an update), and a \emph{failed isolation} in which irrelevant input contaminates it \citep{xu2026should}; in consolidated memory a quarter or more of the agent's own speculations resurface as user-stated facts \citep{verbovoy2026rank}. Failed update is also the base model's default: assistants revise correct answers under pushback \citep{sharma2023towards,atwell2025basil}, drift as context accumulates \citep{geng2025accumulating}, and in context update like a filter that forgets exponentially \citep{zhang2025large}; memory systems write the misconception in \citep{bensal2026recalling}. Independent studies document a fourth, the \emph{failed act}, in which the belief is revised but the policy is not conditioned on it, so that a belief-level oracle finds the diagnosis right while the action stays wrong \citep{deb2026stocktake,gao2026auditing}. \subsection{Mechanisms of Revision}
\label{sec:rev:mech}

The mechanisms that respond to failed update fall into three families by what triggers them. The first is triggered by \emph{contradiction} among stored claims and resolves it with operator algebras, first-class update and forget operations, or supersession contracts \citep{wang2026toki,hao2026memops,xu2026governed,qin2026mom}. The second is triggered \emph{before commitment}, by self-audit, a parametric veto, semantic entropy, or resampling \citep{yuan2026verify,song2026agent,yan2026denoiseflow,wang2026t2po}; these see no future observation and so cannot catch a belief that is consistent and wrong. The third is triggered by \emph{surprise}: reward-prediction error routes writes to a fast or a slow path \citep{song2026d}, and prediction--observation mismatches become semantic rules \citep{zhang2026selfevolvingx}; FinCon revises its investment beliefs after each episode and sends each revision only to the agents that need it, routing the error to an agent though not yet to a claim \citep{yu2024fincon}.

\insight{2}{\textbf{Revision is triggered, not routed.} Contradiction, self-audit, and surprise decide \emph{when} a belief changes; none decides \emph{which claim} the error belongs to. Until the error is routed to the claim that made the prediction, agents will keep repairing memories while beliefs stay wrong.}
