Contextual Belief Management names three ways a belief can fail on new input, a \emph{failed stay} in which the belief moves without evidence (an update no test weighs), a \emph{failed update} in which it survives evidence against it (carried forward without an update), and a \emph{failed isolation} in which irrelevant input contaminates it \citep{xu2026should}. In consolidated memory a quarter or more of the agent's own speculations resurface as user-stated facts \citep{verbovoy2026rank}. Failed update is also the base model's default. Assistants revise correct answers under pushback \citep{sharma2023towards,atwell2025basil}, drift as context accumulates \citep{geng2025accumulating}, and update in context like a filter that forgets exponentially \citep{zhang2025large}, while memory systems write the misconception in \citep{bensal2026recalling}. Independent studies document a fourth, the \emph{failed act}, in which the belief is revised but the policy is not conditioned on it, so that a belief-level oracle finds the diagnosis right while the action stays wrong \citep{deb2026stocktake,gao2026auditing}.
