Only 277 of the 462 included papers give the belief any learning signal; for the rest it is built and revised at inference time (Sections~\ref{sec:representation}--\ref{sec:revision}). Where existing surveys organise post-training by reward source and density \citep{wu2025rewards,zhang2026reasoning,zheng2025prm}, we vary the object that receives the gradient (Figure~\ref{fig:credit}, Table~\ref{tab:learningmain}). Two axes are usually run together: the \emph{credited object}, the quantity that receives the gradient, and the \emph{supervisory source}, whatever signs it (humans, a verifier, the task reward, a teacher, a simulator, or the agent's own later observation). We keep them apart (Table~\ref{tab:learningmain}): a method is at the \emph{state level} if the credited object is a claim about the environment, whatever the source; the source then decides whether the sign exists outside a simulator. A method that rewards a memory write regardless of whether the written claim was true is at the interaction level, however dense its credit.

\subsection{Output and Trajectory}
\label{sec:learn:traj}

Supervised fine-tuning and preference optimisation credit the completed response \citep{ouyang2022training,wei2022finetuned,rafailov2023direct,wang2022self,huang2022large}. Trajectory-level credit began by imitating and searching over agent trajectories \citep{chen2023fireact,zeng2023agenttuning,xi2024agentgym,zhou2023language,putta2024agent,fu2025agentrefine}, then credited sampled steps through PPO, GRPO, and process reward models \citep{schulman2017proximal,shao2024deepseekmath,lightman2023lets,zheng2025prm,zhang2026selfevolving,tan2026hindsight}.

\subsection{Interaction}
\label{sec:learn:inter}

Agentic reinforcement learning credits actions over several turns \citep{zhou2024archer,qi2024webrl,wang2025ragen,chen2025reinforcement,zhou2025sweetrl,feng2025group,dong2025agentic,wu2025collabllm}, and the open question is how to make that credit denser without making it wrong, by hierarchical advantages, counterfactual estimators, potential-based shaping, or verifier-structured credit \citep{peng2026hiper,wang2026capo,diao2026hipif,wang2026groupgraph,ren2026iapo,liao2026tcpo,he2026turns,liu2026pica,xie2026tips,zheng2026pgpo,zhang2026mica,li2026vict,wang2026teach,guo2026hidifftir,qi2026stapo,zhao2026aem,lin2026skillc}; denser is not free \citep{modecrua2026multiturn,pu2026explore}. The nearest this level comes to the state is a group that credits the write to a memory, from a rewritten case bank to an RL-trained overwrite of a fixed written state \citep{zhou2025memento,zhou2025mem1,yu2025memagent,yan2025memory,yu2026agentic,sun2025scaling,zhang2026memskill,jia2026hindsight,sun2026verifiable,pan2026contextpilot,yan2026memoryr2,wang2026tamtrl,ning2026evoharness,wang2026slearl,hu2026collaborative}. These credit the \emph{operation}, so a well-executed update to a wrong claim is still rewarded.

\subsection{State}
\label{sec:learn:state}

The methods that meet the criterion all take the sign of the belief's signal from outside the environment. CBM trains with belief-state rewards from symbolic verification and cuts belief-management failures by about 71\% \citep{xu2026should}, Agent-BRACE trains belief model and policy jointly with verbalised certainty as the belief's output \citep{singh2026agent}, and BOND distils a Bayesian teacher's posterior into an 8B student \citep{cui2026distilling}. VAGEN rewards a written state prediction against the simulator's state \citep{wang2025vagen}, T3 truncates rollouts by a belief deviation anchored to the true hypothesis \citep{zou2025t3}, IGPO and InfoPO reward a turn by the belief update it causes toward the known answer \citep{wang2025information,kong2026infopo}, Dyna-Think, SPA, and RLVR-World train state prediction as a loss or verifiable reward \citep{yu2025dynathink,chen2025why,wu2025rlvrworld}, OASES scores each intermediate search state by how well it supports the answer \citep{zhang2026oases}, and DEL-ToM scores each belief-update step with a process belief model \citep{wu2025deltom}. Each needs the answer or the latent state at training time; the pre-LLM belief graph learned from observations alone \citep{adhikari2020learning} has no language-model successor.

\insight{3}{\textbf{Credit has been getting denser, not deeper.} Agentic reinforcement learning has refined which action to prefer; no method changed what the action is conditioned on. The two axes are orthogonal, and the first system to combine them will need a sign for its belief that the environment, not an oracle, supplies.}
